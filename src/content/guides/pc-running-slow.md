  - 프로그램을 여는 데 오래 걸린다.

causes:
  - 동시에 실행 중인 프로그램이 많다.
  - 저장공간이 부족하거나 업데이트가 진행 중이다.
  - 특정 앱이나 백그라운드 작업이 자원을 많이 사용한다.
checks:
  - PC를 재부팅한 직후에도 느린지 확인합니다.
  - 작업 관리자에서 CPU, 메모리, 디스크 사용량을 확인합니다.
  - 저장공간에 여유가 있는지 확인합니다.
solutions:
  - title: 재부팅 후 증상을 다시 확인합니다.
    body: 오랫동안 종료하지 않은 PC라면 열려 있던 작업이 정리됩니다. 재부팅 직후에도 느리면 다음 단계를 진행합니다.
  - title: 자원을 많이 사용하는 앱을 확인합니다.
    body: Windows 작업 관리자에서 CPU·메모리·디스크 열을 차례로 정렬합니다. 이름을 아는 앱이 과도하게 사용 중이면 저장할 내용을 저장한 뒤 종료합니다.
  - title: 시작 앱과 저장공간을 정리합니다.
    body: 작업 관리자의 시작 앱 탭에서 필요하지 않은 앱의 자동 실행을 끌 수 있습니다. 저장공간은 큰 개인 파일부터 검토하며 시스템 파일은 임의로 삭제하지 않습니다.
warnings:
  - 레지스트리 정리 프로그램이나 출처가 불분명한 최적화 프로그램을 설치하지 않습니다.

## 한눈에 보기

재부팅으로 일시적인 상태를 배제한 다음, 작업 관리자에서 실제로 자원을 사용하는 항목을 찾습니다.

## 가능한 원인

느림은 하나의 원인보다 실행 중인 작업, 저장공간, 특정 앱이 함께 영향을 주는 경우가 많습니다.

## 그래도 해결되지 않을 때

안전 모드나 하드웨어 점검이 필요한지 판단하기 전에, 느려지는 시점과 실행 중인 앱을 기록해 증상을 비교하세요.
